# Mural 1–40

A responsive, interactive mural of 40 image/text slides.

## Deploy on GitHub Pages

1. Create a GitHub repository.
2. Upload `index.html` and the `images/` folder.
3. Enable **Settings → Pages → Deploy from a branch**.
4. Select the branch and the root folder.

The mural uses relative image paths, so it works from GitHub Pages without any server-side setup.

## Interaction

- Desktop: 8 columns × 5 rows.
- Phone portrait: 5 columns × 8 rows.
- The opening begins with the small Abdymok walking figure centered on white for about five seconds.
- The mural then emerges gradually through mist.
- All populated tiles begin as small breathing images.
- Clicking a populated tile enlarges it to a 3×3 hero and dissolves to its text side.
- The mural pauses while the text is read.
- Clicking the hero returns it to the image wall and resumes recomposition.
- The wall periodically recomposes with slow dissolves and multiple hero tiles.
- Slides 39 and 40 are currently reserved placeholders.
